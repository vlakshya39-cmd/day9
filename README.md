# Day 9 – NutriScope Nutrition Intelligence App

## Overview

NutriScope is a nutrition tracking web application created using AI-assisted development.

This project demonstrates how prompt engineering can be used to generate and improve a complete web application using Claude.

The project compares:

1. MVP Version (Prompt 1)
2. Enhanced Version (Prompt 2)

---

## Objective

Build a nutrition tracking application that allows users to:

- Create a personal profile
- Calculate calorie and nutrition targets
- Log foods consumed
- View nutrition dashboards
- Receive nutrition recommendations

---

## Version 1 – MVP

Features:

- User profile setup
- Age, weight, height, activity level inputs
- TDEE calculation
- Food logging
- Nutrition dashboard
- Macronutrient tracking
- Personalized nutrition advice

File:

`nutriscope.html`

---

## Version 2 – Enhanced

Additional Features:

- Improved UI and UX
- CSV food import
- Meal planner
- Risk analysis dashboard
- Nutrition source references
- Advanced charts and analytics
- Goal-based nutrition planning
- Educational nutrition disclaimers

File:

`nutriscope-v2.html`
